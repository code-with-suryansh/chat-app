
## 💻 Usage

### Registration
1. Click "Register" on the login page
2. Enter username and password
3. Submit to create account

### Login
1. Enter your credentials
2. Click "Login" to access chat

### Messaging
- **Public Chat**: Messages are visible to all users
- **Private Messages**: Click a user's name to start private chat
- **Switch Modes**: Use "Everyone" option to return to public chat
